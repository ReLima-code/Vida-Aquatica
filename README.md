# Vida Aquática

Aplicação web educativa sobre conscientização e preservação da vida aquática, desenvolvida como Atividade Extensionista (ADS - UNINTER).

## Sobre o projeto

Site com foco no litoral norte de São Paulo (Caraguatatuba), com conteúdo sobre:

- Vida marinha e seus ecossistemas
- ONGs e redes de conservação ambiental
- Ações comunitárias (mutirões de limpeza) com dados reais de organizações
- Conteúdo educativo com quiz interativo
- Formulário de contato para conectar com ONGs parceiras

## Estrutura de pastas

```
vida-aquatica/
├── index.html              (página inicial)
├── educacao-estudos.html   (página de educação e estudos)
├── sobreVidaMarinha.html   (página sobre vida marinha)
├── index.js                (menu, mapas e carrossel)
├── contato.js              (envio do formulário de contato)
├── css/
│   ├── index.css
│   ├── educacao-estudos.css
│   └── sobreVidaMarinha.css
└── imagens/
    (imagens usadas no site)
```

## Tecnologias usadas

- HTML5, CSS3 e JavaScript puro (sem frameworks)
- [Leaflet.js](https://leafletjs.com/) para os mapas interativos
- [Font Awesome](https://fontawesome.com/) para os ícones
- [Formspree](https://formspree.io/) para o envio do formulário de contato

## Como rodar localmente

Basta abrir o `index.html` em um navegador. Como o site usa apenas arquivos estáticos, não precisa de servidor nem de instalação.
